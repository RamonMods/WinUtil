description: Problemas conhecidos do WinUtil e como contorná-los.
---

### Download não funciona

Se você executar o WinUtil e receber um erro como:

`< : The term '<' is not recognized as the name of a cmdlet, function, script file, or operable program.`

tente usar uma **VPN** e, se isso não funcionar, relate o problema em https://github.com/RamonMods/WinUtil/issues

### O script não executa

Se você executar o WinUtil e receber o erro:

`"WinUtil is unable to run on your system. PowerShell execution is restricted by security policies"`

Isso significa que sua sessão do PowerShell está em **Modo de Linguagem Restrita** (Constrained Language Mode), o que impede o WinUtil de ser executado.

### Plano Alto Desempenho Máximo não funciona

O plano de energia Alto Desempenho Máximo pode não funcionar em alguns notebooks que não oferecem suporte completo a esse plano.

Nesses casos, o plano pode falhar ao ser aplicado. Esse é o comportamento esperado em hardware sem suporte.

### O ajuste de reverter o menu Iniciar não funciona

O ajuste de reverter o menu Iniciar deixa de funcionar a partir da **atualização KB5089573 do Windows 11** (lançada em maio de 2026).

Nessa atualização, a Microsoft removeu completamente o código antigo do Menu Iniciar do Windows, então não conseguimos trazê-lo de volta.

### Problemas com o PowerShell 7 ou erro Class not registered
Instalar o PowerShell 7 pela Microsoft Store (pacote MSIX) é conhecido por causar problemas com cmdlets do DISM, como `Get-WindowsOptionalFeature` e `Enable-WindowsOptionalFeature`, resultando em um erro COM `Class not registered`.

Isso também pode fazer com que a "remoção de aplicativos pré-instalados" leve um tempo indeterminado

Em vez disso, instale o PowerShell 7 usando um dos seguintes métodos:

**winget (recomendado):**
```powershell
winget install --id Microsoft.PowerShell --source winget --installer-type wix
```
**MSI direto das releases do GitHub:** Baixe o instalador `.msi` na página de [releases do PowerShell no GitHub](https://github.com/PowerShell/PowerShell/releases).

Para mais detalhes, veja https://github.com/PowerShell/PowerShell/issues/13866
