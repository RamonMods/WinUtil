Veja o que cada ajuste altera antes de executá-lo. Abra um ajuste para ver os valores de registro e os tipos de inicialização de serviço que ele define ao lado do que o **Desfazer** restaura, junto com qualquer script que ele execute. A busca também encontra caminhos de registro, nomes de serviços e conteúdos de scripts, para você localizar todo ajuste que mexe em uma determinada configuração. Use **Adicionar à configuração** nos ajustes de caixa de seleção e de interruptor compatíveis e depois abra-os no [Construtor de configurações](/config-builder/) pelo link acima da lista. Para interruptores, **Adicionar à configuração (Quando ligado)** seleciona apenas o estado ligado; configurações não conseguem selecionar o estado desligado.

A lista é carregada da versão mais recente do WinUtil no GitHub, a mesma versão que `https://github.com/RamonMods/WinUtil/releases/latest/download/winutil.ps1` executa.

Listas suspensas baseadas em registro, como Multiplane Overlay, mostram uma coluna para cada estado disponível. Escolha o estado no WinUtil para aplicá-lo imediatamente. Esses controles não usam **Desfazer ajustes selecionados**; escolha outro estado para revertê-los.

**Tem desfazer** significa que existe pelo menos uma ação de desfazer de registro, serviço ou script disponível, e não que ela restaura exatamente o seu estado anterior. Um ajuste também pode mostrar **O script não tem desfazer** ou **A remoção de AppX não tem desfazer** quando apenas parte das mudanças pode ser desfeita. Por exemplo, o Desfazer pode reinstalar o Microsoft Edge, mas não consegue recuperar o perfil do navegador apagado pelo ajuste de remoção.

Um ajuste marcado como **O script não tem desfazer** ou **A remoção de AppX não tem desfazer** é aquele que o Desfazer não consegue reverter por completo. Alguns são ações pontuais sem nada a restaurar, como criar um ponto de restauração ou limpar arquivos temporários. Para os demais, crie um ponto de restauração antes de aplicá-los.
