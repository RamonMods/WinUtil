Monte um arquivo de configuração do WinUtil sem abrir o WinUtil. Selecione o que quiser, baixe o arquivo e execute o WinUtil com `-Config`, conforme descrito em [Automação](/guides/automation/).

A lista é carregada da versão estável mais recente do WinUtil no GitHub. O comando gerado executa exatamente essa versão, então as chaves selecionadas continuam compatíveis mesmo que uma versão mais nova seja publicada antes de você executá-lo.

<ConfigBuilder client:load />

- **Padrão**, **Mínimo** e **Avançado** substituem os ajustes selecionados por essa predefinição, igual aos botões de predefinição no WinUtil. Seus interruptores e outras seleções continuam como estão.
- Os interruptores em **Personalizar preferências** são ativados quando a configuração é executada. Uma configuração não consegue desativar um interruptor.
- **Remoção de AppX** seleciona os pacotes a remover quando a configuração é executada. **Remoções padrão** seleciona a lista de remoção padrão do WinUtil; ela não instala nem mantém esses apps.
- **Compartilhar link** copia um link com suas seleções. Abrir o link seleciona os mesmos itens, o que é um jeito fácil de divulgar uma configuração sem passar um arquivo adiante.
- **Abrir uma configuração** carrega um arquivo exportado para você alterá-lo. As chaves que a versão atual não possui são listadas e descartadas, o que também é uma forma rápida de corrigir um erro `Unknown selection key`.
- Se o seu navegador salva downloads em outro lugar que não a pasta `Downloads`, altere o caminho no comando para corresponder.
