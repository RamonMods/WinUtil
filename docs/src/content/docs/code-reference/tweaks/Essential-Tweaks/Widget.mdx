:::note
Esta página é gerada a partir de [`config/tweaks.json`](https://github.com/RamonMods/WinUtil/blob/main/config/tweaks.json). Não edite esta página diretamente.
:::

```json title="config/tweaks.json"
  "WPFTweaksWidget": {
    "Content": "Widgets - Remover",
    "Description": "Remove os widgets irritantes do canto inferior esquerdo da barra de tarefas.",
    "category": "Essential Tweaks",
    "panel": "1",
    "InvokeScript": [
      "
      # Sometimes if you dont stop the Widgets process the removal may fail

      Get-Process *Widget* | Stop-Process
      Get-AppxPackage Microsoft.WidgetsPlatformRuntime -AllUsers | Remove-AppxPackage -AllUsers
      Get-AppxPackage MicrosoftWindows.Client.WebExperience -AllUsers | Remove-AppxPackage -AllUsers

      Invoke-WinUtilExplorerUpdate -action \"restart\"
      Write-Host \"Removed widgets\"
      "
    ],
  }
```
