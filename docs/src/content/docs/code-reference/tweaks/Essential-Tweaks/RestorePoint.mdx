```json title="config/tweaks.json"
  "WPFTweaksRestorePoint": {
    "Content": "Ponto de Restauração - Criar",
    "Description": "Cria um ponto de restauração em tempo de execução, caso seja necessário reverter alterações feitas pelo WinUtil.",
    "category": "Essential Tweaks",
    "panel": "1",
    "Checked": "False",
    "registry": [
      {
        "Path": "HKLM:\\SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion\\SystemRestore",
        "Name": "SystemRestorePointCreationFrequency",
        "Value": "0",
        "Type": "DWord",
        "OriginalValue": "1440"
      }
    ],
    "InvokeScript": [
      "
      if (-not (Get-ComputerRestorePoint)) {
          Enable-ComputerRestore -Drive $Env:SystemDrive
      }

      Checkpoint-Computer -Description \"System Restore Point created by WinUtil\" -RestorePointType MODIFY_SETTINGS
      Write-Host \"System Restore Point Created Successfully\" -ForegroundColor Green
      "
    ],
  }
```

## Alterações no Registro

Aplicativos e componentes do sistema armazenam e recuperam dados de configuração para modificar as configurações do Windows, então podemos usar o registro para alterar muitas configurações em um só lugar.

Você pode encontrar informações sobre o registro na [Wikipedia](https://en.wikipedia.org/wiki/Windows_Registry) e no [site da Microsoft](https://learn.microsoft.com/en-us/windows/win32/sysinfo/registry).
