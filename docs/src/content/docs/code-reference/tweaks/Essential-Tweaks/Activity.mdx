## Alterações no Registro

Aplicativos e Componentes do Sistema armazenam e recuperam dados de configuração para modificar as configurações do Windows, então podemos usar o registro para alterar muitas configurações em um só lugar.

Você pode encontrar informações sobre o registro na [Wikipedia](https://en.wikipedia.org/wiki/Windows_Registry) e no [site da Microsoft](https://learn.microsoft.com/en-us/windows/win32/sysinfo/registry).
