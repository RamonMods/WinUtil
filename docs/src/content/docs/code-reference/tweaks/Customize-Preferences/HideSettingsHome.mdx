:::note
Esta página é gerada a partir de [`config/tweaks.json`](https://github.com/RamonMods/WinUtil/blob/main/config/tweaks.json). Não edite esta página diretamente.
:::

```json title="config/tweaks.json"
  "WPFToggleHideSettingsHome": {
    "Content": "Página inicial de Configurações",
    "Description": "Alterna a Página Inicial no aplicativo Configurações do Windows.",
    "category": "Customize Preferences",
    "panel": "2",
    "Type": "Toggle",
    "registry": [
      {
        "Path": "HKCU:\\Software\\Microsoft\\Windows\\CurrentVersion\\Policies\\Explorer",
        "Name": "SettingsPageVisibility",
        "Value": "show:home",
        "Type": "String",
        "OriginalValue": "hide:home",
        "DefaultState": "true"
      }
    ],
  }
```

## Alterações no Registro

Aplicativos e componentes do sistema armazenam e recuperam dados de configuração para modificar as configurações do Windows, então podemos usar o registro para alterar muitas configurações em um só lugar.

Você pode encontrar informações sobre o registro na [Wikipedia](https://en.wikipedia.org/wiki/Windows_Registry) e no [site da Microsoft](https://learn.microsoft.com/en-us/windows/win32/sysinfo/registry).
