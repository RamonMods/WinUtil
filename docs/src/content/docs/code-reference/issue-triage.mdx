---
title: Comandos de triagem de issues
description: Comandos que mantenedores de confiança podem usar para rotular e encerrar issues do GitHub.
---

Membros de confiança do repositório cujos IDs numéricos de usuário do GitHub estão listados no workflow de triagem de issues podem executar os comandos abaixo. Esses comandos funcionam apenas em issues. Comentários em pull requests são ignorados, e o token do workflow não tem permissão de escrita em pull requests.

## Comandos

- `/triage` adiciona o rótulo `needs-triage`.
- `/triageoff` remove o rótulo `needs-triage` quando ele estiver presente.
- `/np` encerra a issue como não planejada.
- `/np wontfix` adiciona o rótulo `wontfix` sem substituir os rótulos existentes e então encerra a issue como não planejada.
- `/np notrelated` adiciona o rótulo `not-related` sem substituir os rótulos existentes e então encerra a issue como não planejada.
- `/np <reason>` encerra a issue como não planejada sem adicionar rótulo para motivos não reconhecidos.
- `/duplicate <issue number>` encerra a issue como duplicada de outra issue. O número positivo da issue pode começar, opcionalmente, com `#`; números de pull request são rejeitados.

## Tratamento dos comandos

Coloque exatamente um comando no comentário. Espaços no início e no fim são permitidos, mas texto antes ou depois do comando não é. A correspondência de comandos não diferencia maiúsculas de minúsculas, e números de issue malformados são rejeitados.

Depois que um comando é tratado, o workflow apaga o comentário do comando e deixa um comentário de auditoria descrevendo o resultado. Um destino de duplicação ausente ou um pedido para duplicar uma issue nela mesma é relatado sem encerrar a issue. Falhas inesperadas da API do GitHub interrompem o workflow e deixam o comentário do comando disponível para nova tentativa.

## Acesso

O acesso é concedido adicionando o ID numérico imutável do usuário do GitHub do membro de confiança ao arquivo `.github/workflows/triage-tools.yaml` por meio de um pull request. O abuso pode resultar na remoção da lista de permitidos ou em outra ação de moderação do repositório.
