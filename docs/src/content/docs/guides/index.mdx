Bem-vindo ao Guia do Usuário oficial do **Winutil**, seu kit de ferramentas tudo-em-um para Windows.

:::caution
O Windows 10 não é suportado pelo Winutil. O Windows 10 chegou ao fim do suporte em **14 de outubro de 2025**.
:::

## O que é o Winutil?

O Winutil (o utilitário Windows do Ramon) é uma ferramenta abrangente baseada em PowerShell que ajuda você a:

- **Instalar aplicativos**: Instale rapidamente softwares populares sem downloads manuais
- **Aplicar ajustes**: Otimize o Windows para desempenho, privacidade e usabilidade
- **Corrigir problemas**: Solucione problemas comuns do Windows com correções em um clique
- **Gerenciar atualizações**: Controle como e quando as atualizações do Windows são instaladas
- **Acessar ferramentas**: Acesso rápido a painéis e utilitários do Windows

## Quem deve usar o Winutil?

O Winutil foi feito para:

- **Usuários domésticos**: Pessoas que querem otimizar seus PCs pessoais
- **Usuários avançados**: Usuários que querem controle refinado sobre o Windows
- **Profissionais de TI**: Equipes que gerenciam vários sistemas com eficiência
- **Jogadores**: Usuários que otimizam sistemas para desempenho em jogos
- **Usuários preocupados com privacidade**: Pessoas que reduzem telemetria e coleta de dados
- **Desenvolvedores**: Usuários que montam ambientes de desenvolvimento limpos

## Segurança e boas práticas

Antes de usar o Winutil:

✅ **Sempre**:
- Execute o PowerShell como Administrador
- Crie um ponto de restauração do sistema antes de mudanças grandes
- Entenda o que os ajustes fazem antes de aplicá-los
- Comece pelos Ajustes essenciais antes dos avançados
- Mantenha backups dos dados importantes

❌ **Nunca**:
- Aplique todos os ajustes sem entendê-los
- Deixe de criar pontos de restauração
- Use em sistemas de produção sem testar
- Desabilite recursos de segurança sem necessidade

## Requisitos do sistema

- **Sistema operacional**: Windows 11
- **PowerShell**: Versão 5.1 ou superior (incluída no Windows 11)
- **Permissões**: Acesso de Administrador obrigatório
- **Internet**: Necessária para baixar apps e atualizações
- **.NET Framework**: 4.5+ (normalmente pré-instalado)
