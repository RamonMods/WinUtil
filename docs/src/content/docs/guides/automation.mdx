Use Automação para executar o WinUtil a partir de um arquivo de configuração exportado.

O WinUtil suporta predefinições que aplicam configurações comuns automaticamente:

- `Standard`
- `Minimal`
- `Advanced`

Exemplo:

```powershell
& ([ScriptBlock]::Create((irm "https://github.com/RamonMods/WinUtil/releases/latest/download/winutil.ps1"))) -Preset Standard
```

Para ver exatamente o que cada predefinição faz, consulte:
https://github.com/RamonMods/WinUtil/blob/main/config/preset.json

Para descobrir a chave de uma configuração personalizada, passe o mouse sobre um aplicativo, ajuste, recurso ou entrada AppX compatível no WinUtil. A dica mostra `Chave da predefinição: <key>`. As chaves de aplicativos podem ser buscadas na aba Instalar, enquanto as de ajustes e AppX podem ser buscadas nas abas respectivas. As chaves de recursos estão disponíveis nas dicas porque a aba Configurações/Recursos não tem busca. Controles que não podem ser aplicados por uma predefinição, como interruptores, listas suspensas e escolhas de gerenciador de pacotes, deliberadamente não exibem uma chave de predefinição.

Para criar seu próprio arquivo de configuração:

1. Abra o WinUtil.
2. Clique no ícone de engrenagem no canto superior direito.
3. Escolha **Exportar**.
4. Salve o arquivo JSON exportado.

Para montar uma configuração sem abrir o WinUtil, faça suas seleções no navegador com o [Config Builder](/config-builder/) e baixe o arquivo por lá.

Use o comando gerado pelo Config Builder com o arquivo baixado por ele. Ele executa a versão usada para montar o catálogo, mantendo as seleções compatíveis caso uma versão mais nova remova ou renomeie chaves.

Os caminhos locais de configuração são usados exatamente como fornecidos ao importar ou exportar. Colchetes em nomes de pastas ou arquivos, como `C:\Configs\setup[1].json`, são tratados como parte do nome, e não como padrões curinga.

Use URLs HTTPS ou arquivos locais confiáveis para configurações. URLs HTTP não protegem a integridade da configuração, então um atacante na rede poderia substituir as ações selecionadas. O WinUtil lê respostas remotas como dados JSON, sem processar scripts de páginas web. Respostas JSON inválidas são rejeitadas antes que as seleções atuais mudem.

A exportação também copia para a área de transferência um comando que inicia o WinUtil com a configuração salva. O comando copiado preserva caracteres especiais no caminho, incluindo apóstrofos, cifrões e acentos graves.

Você também pode iniciar o WinUtil com uma configuração exportada usando este comando:
```powershell
& ([ScriptBlock]::Create((irm "https://github.com/RamonMods/WinUtil/releases/latest/download/winutil.ps1"))) -Config "C:\Path\To\Config.json"
```

Chaves repetidas em uma configuração importada selecionam cada entrada apenas uma vez. Desmarcar uma entrada importada a remove da seleção, mesmo que a chave dela apareça mais de uma vez no arquivo.

Isso é útil para:

- Aplicar a mesma configuração do WinUtil em vários PCs com Windows 11
- Reutilizar uma linha de base confiável após reinstalar o Windows
- Padronizar implantações para laboratórios, estações de trabalho ou configurações pessoais

:::caution[Mantenha as configurações exportadas atualizadas]
As configurações exportadas contêm as chaves do catálogo do WinUtil que existiam quando o arquivo foi criado. As exportações atuais usam um formato JSON plano: uma string quando uma única configuração está selecionada, ou um array de strings quando várias estão selecionadas. Se uma versão posterior do WinUtil remover ou renomear qualquer chave importada, a importação inteira é rejeitada antes que as seleções atuais sejam alteradas. O PowerShell relata a entrada obsoleta como `Unknown selection key '<key>'`.

Versões mais antigas do WinUtil exportavam um objeto JSON com metadados de pacote `Install` e seleções agrupadas `WPFInstall`, `WPFTweaks`, `WPFToggle` e `WPFFeature`. Ao importar um desses arquivos legados, o WinUtil restaura as chaves que ainda existem e ignora as chaves retiradas, registrando-as como aviso no log do WinUtil. Se o arquivo não contiver nenhuma seleção compatível, a importação não faz mudanças.

Para se recuperar, compare a chave relatada com os arquivos atuais no [catálogo de configurações do WinUtil](https://github.com/RamonMods/WinUtil/tree/main/config). Remova ou substitua a chave obsoleta no seu arquivo JSON, ou crie e exporte uma nova configuração com a versão atual do WinUtil e execute a importação de novo. Reexporte linhas de base de longa duração após mudanças no catálogo, para que continuem compatíveis.
:::

:::note
Execute o comando em uma sessão elevada do PowerShell para que o WinUtil possa aplicar mudanças no nível do sistema.
:::
