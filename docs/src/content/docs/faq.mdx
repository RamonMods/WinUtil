## Perguntas gerais

### O Windows 10 ainda é suportado?

Não. O Windows 10 não é mais suportado pelo WinUtil porque chegou ao fim do suporte em **14 de outubro de 2025**. O WinUtil é focado no Windows 11.

### Como desinstalo o WinUtil?

Você não precisa desinstalar o WinUtil. Como ele é executado como um script PowerShell, é carregado na memória apenas enquanto está aberto. Ao fechá-lo, ele é removido da memória e não permanece instalado no sistema.

### O WinUtil é seguro?

Sim, o WinUtil é de código aberto e o código está disponível publicamente no GitHub. Milhares de usuários o executam diariamente. No entanto, como qualquer ferramenta de modificação do sistema, você deve:

- Executá-lo como Administrador (obrigatório)
- Criar um ponto de restauração antes de mudanças grandes
- Entender quais ajustes você está aplicando
- Executar somente a partir da [fonte oficial](https://github.com/RamonMods/WinUtil/)

### Preciso deixar o WinUtil rodando?

Não. Depois de aplicar ajustes ou instalar aplicativos, você pode fechar o WinUtil. As mudanças persistem após o fechamento. Você só precisa executar o WinUtil de novo quando quiser fazer mudanças adicionais ou desfazer ajustes.

### O WinUtil precisa de acesso à internet?

- **Para baixar**: Sim, instalar aplicativos exige internet
- **Para ajustes**: Não, a maioria dos ajustes funciona offline
- **Primeira execução**: Sim, para executar o script mais recente

### Com que frequência o WinUtil é atualizado?

O WinUtil é mantido ativamente, com atualizações frequentes. Novos recursos, correções de bugs e novos aplicativos são lançados regularmente. O script baixa automaticamente a versão mais recente toda vez que você o executa.

## Instalação e execução

### Como executo o WinUtil?

1. Abra o PowerShell como Administrador
2. Execute: `irm "https://github.com/RamonMods/WinUtil/releases/latest/download/winutil.ps1" | iex`
3. Aguarde a interface gráfica aparecer

### Por que preciso de direitos de Administrador?

O WinUtil faz alterações no nível do sistema (edições de registro, modificações de serviços, instalação de software) que exigem permissões elevadas. Sem direitos de administrador, a maioria dos recursos não funciona.

### O script não baixa. O que faço?

Tente estas soluções na ordem:

1. **Use o link direto do GitHub**:

   ```powershell
   irm https://github.com/RamonMods/WinUtil/releases/latest/download/Winutil.ps1 | iex
   ```

2. **Force o TLS 1.2**:

   ```powershell
   [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
   irm "https://github.com/RamonMods/WinUtil/releases/latest/download/winutil.ps1" | iex
   ```

   :::note
   No Windows 11, você normalmente não precisa do comando de TLS 1.2. Use-o apenas se encontrar erros de download ou de protocolo de segurança.
   :::

3. **Troque o DNS** para Cloudflare (1.1.1.1) ou Google (8.8.8.8)
4. **Use uma VPN** se o GitHub estiver bloqueado na sua região

### Recebo um erro de "Execution Policy". Como corrijo?

Execute este comando primeiro para permitir a execução de scripts:

```powershell
Set-ExecutionPolicy Unrestricted -Scope Process -Force
irm "https://github.com/RamonMods/WinUtil/releases/latest/download/winutil.ps1" | iex
```

Isso afeta apenas a sessão atual do PowerShell e é seguro.

## Ajustes e modificações

### Apliquei um ajuste e agora algo não funciona. O que faço?

Se você aplicou um ajuste e ele quebrou algo, pode revertê-lo:

1. Abra o WinUtil novamente
2. Vá para a aba **Ajustes**
3. Selecione o mesmo ajuste que você aplicou
4. Clique em **Desfazer ajustes selecionados**
5. O sistema voltará ao estado anterior

Como alternativa, use a Restauração do Sistema se você criou um ponto de restauração.

### Quais ajustes são seguros de aplicar?

**Seguros para todos (Ajustes essenciais)**:

- Desabilitar telemetria
- Desabilitar histórico de atividades
- Desabilitar rastreamento de localização
- Excluir arquivos temporários
- Executar Limpeza de Disco
- Criar ponto de restauração

**Ajustes avançados** devem ser executados apenas por usuários avançados.

### Os ajustes sobrevivem às atualizações do Windows?

A maioria dos ajustes persiste após as atualizações, mas alguns podem ser redefinidos por atualizações de recursos maiores do Windows. Talvez seja necessário reaplicar certos ajustes depois.

### Posso criar minhas próprias predefinições de ajustes?

Atualmente o WinUtil usa predefinições fixas (Padrão, Mínimo). Predefinições personalizadas não são suportadas diretamente na interface, mas você pode criar um script com a configuração que preferir.

### Qual a diferença entre ajustes essenciais e avançados?

- **Ajustes essenciais**: Seguros para a maioria dos usuários, melhoram desempenho/privacidade com risco mínimo
- **Ajustes avançados**: Mudanças mais agressivas que podem quebrar funcionalidades ou compatibilidade. Use com cuidado.

## Instalação de aplicativos

### Como o WinUtil instala aplicativos?

O WinUtil usa o Windows Package Manager (WinGet) e o Chocolatey para automatizar as instalações. Ele baixa os aplicativos de fontes oficiais e os instala silenciosamente, sem bloatware.

### Posso instalar vários aplicativos de uma vez?

Sim! Marque as caixas de seleção de todos os aplicativos que quiser e clique em "Instalar selecionados". Eles serão instalados em sequência.

### O WinGet não está funcionando. Como corrijo?

1. Vá para a aba **Configurações**
2. Encontre a seção **Correções**
3. Clique em **Reinstalar o WinGet**
4. Aguarde a conclusão
5. Tente instalar os aplicativos novamente

### Os aplicativos instalados têm bloatware ou software empacotado?

Não. WinGet e Chocolatey instalam versões limpas dos aplicativos, sem ofertas empacotadas, barras de ferramentas ou bloatware.

### Posso desinstalar aplicativos pelo WinUtil?

O WinUtil foca principalmente em instalar e gerenciar aplicativos, e não em oferecer uma interface completa para desinstalar todos os programas. Para remover aplicativos, você pode:

- Usar Configurações > Aplicativos > Aplicativos instalados do Windows para desinstalar programas.
- Usar comandos de gerenciadores de pacotes no PowerShell (por exemplo `winget uninstall <package>` ou `choco uninstall <package>`).
- Alguns pacotes instalados pelo WinUtil (AppX/MSIX) incluem auxiliares de remoção; verifique a entrada do aplicativo ou use os auxiliares de remoção do WinUtil quando disponíveis.

### Os aplicativos instalados são atualizados automaticamente?

Aplicativos com mecanismos de atualização próprios são atualizados automaticamente. Você também pode atualizá-los por comandos do WinGet/Chocolatey ou pelo recurso "Atualizar selecionados" do WinUtil.

## Atualizações e manutenção

### Devo desabilitar as atualizações do Windows?

Em geral, **não**. As atualizações de segurança são importantes. Porém, você pode:

- Usar "Somente atualizações de segurança" para evitar atualizações de recursos
- Pausar as atualizações temporariamente por estabilidade
- Desabilitar apenas durante períodos de trabalho crítico

### Como reabilito as atualizações depois de desabilitá-las?

1. Abra o WinUtil
2. Vá para a aba **Atualizações**
3. Clique em **Atualizações padrão**
4. As atualizações voltarão ao normal

### Qual a diferença entre "Somente atualizações de segurança" e "Desabilitar atualizações"?

- **Somente atualizações de segurança**: Instala patches de segurança críticos, bloqueia atualizações de recursos (versões principais)
- **Desabilitar atualizações**: Bloqueia TODAS as atualizações, incluindo as de segurança (não recomendado)

## Solução de problemas

### O WinUtil não abre depois de executar o comando

Causas possíveis:

1. **Antivírus bloqueando**: Adicione uma exceção para o PowerShell
2. **Não executado como Admin**: Reinicie o PowerShell como Administrador
3. **Download corrompido**: Feche o PowerShell, reabra e tente de novo
4. **Windows Defender**: Permita o script

### Meu antivírus marca o WinUtil como malicioso

Isso é um falso positivo. O WinUtil faz alterações no sistema que programas antivírus podem sinalizar. O código é de código aberto e auditado. Adicione uma exceção se necessário.

### Um aplicativo falhou ao instalar

Passos para solucionar:

1. Verifique sua conexão com a internet
2. Tente instalar apenas esse aplicativo
3. Verifique as mensagens de erro no painel de saída
4. Verifique se o antivírus está bloqueando
5. Tente a correção Reinstalar o WinGet

### Ajustes de rede quebraram minha conexão com a internet

1. Abra o WinUtil
2. Vá para **Configurações** > **Correções**
3. Clique em **Redefinir rede**
4. Reinicie o computador
5. A conexão deve ser restaurada

### Não consigo acessar certos recursos do Windows depois de aplicar ajustes

Desfaça os ajustes que possam ter afetado esses recursos:

1. Reabra o WinUtil
2. Selecione os ajustes que você aplicou
3. Clique em **Desfazer ajustes selecionados**

Se isso não funcionar, use a Restauração do Sistema para voltar a um estado anterior.

## Tópicos avançados

### Posso executar o WinUtil no Windows Server?

Sim, o WinUtil funciona nas edições do Windows Server, embora alguns recursos possam não se aplicar ou se comportar de forma diferente.

### O WinUtil funciona com o Windows LTSC?

Atualmente o WinUtil tem como alvo o Windows 11. O Windows 10 LTSC não é suportado, de acordo com a política de suporte ao Windows 10 acima. Alguns recursos e aplicativos podem variar conforme a edição do Windows 11.

### Posso usar o WinUtil em ambiente corporativo/empresarial?

Sim, mas consulte primeiro as políticas da sua organização. Alguns ajustes podem conflitar com a Diretiva de Grupo ou outros requisitos corporativos.

## Privacidade e segurança

### O WinUtil coleta algum dado?

Não, o próprio WinUtil não coleta nem transmite dados de usuário. É um script PowerShell local.

### Que telemetria o ajuste Desabilitar telemetria bloqueia?

Ele desabilita:

- Coleta de dados de diagnóstico do Windows
- Rastreamento do histórico de atividades
- Solicitações de feedback
- Estatísticas de uso
- Relatórios de erro (opcional)

### Remover a Microsoft Store afeta as atualizações de segurança?

Não, as atualizações de segurança do Windows são independentes da Microsoft Store.

## Desempenho

### O WinUtil deixa meu PC mais rápido?

Os ajustes podem melhorar o desempenho ao:

- Reduzir processos em segundo plano
- Desabilitar serviços desnecessários
- Limpar arquivos temporários
- Otimizar programas de inicialização

Os resultados podem variar conforme o seu sistema.

### Qual a melhor predefinição para jogos?

Use a predefinição **Desktop** e aplique ainda:

- Desabilitar GameDVR
- Plano de energia Alto Desempenho Máximo
- Desabilitar otimizações de tela cheia (Avançado)
- Definir exibição para desempenho (Avançado)

### Quanta RAM o WinUtil usa?

O próprio WinUtil usa cerca de 50-100 MB enquanto está em execução. Depois de fechado, é removido da memória.

## Mensagens de erro

### Erros de "Acesso negado"

- Verifique se o PowerShell está sendo executado como Administrador
- Verifique se o antivírus está bloqueando mudanças
- Confirme se você tem a propriedade dos arquivos/chaves de registro

### "GitHub rate limit has been reached"

Algumas páginas deste site, como o [Config Builder](/config-builder/) e o [Tweak Explorer](/tweak-explorer/), carregam seus dados da versão mais recente do WinUtil no GitHub quando você as abre. Sem autenticação, o GitHub permite apenas 60 requisições por hora por endereço IP, e todos que compartilham sua conexão, como uma rede doméstica, de escritório ou escolar, contam para o mesmo limite. Essas páginas usam apenas uma dessas requisições por sessão do navegador, mas, quando o limite acaba, elas precisam esperar o GitHub liberá-lo.

Aguarde um pouco e selecione **Tentar novamente**. O restante da documentação não é afetado.
